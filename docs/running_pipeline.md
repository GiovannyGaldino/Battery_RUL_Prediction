# Running the pipeline

Run commands from the repository root. All examples use relative paths so they can be executed on any machine after the raw files have been placed under `data/raw`.

## 1. Dataset adapters

Run one dataset adapter at a time:

```bash
python scripts/run_adapter.py --dataset matr --base-dir . --stage all
python scripts/run_adapter.py --dataset calce --base-dir . --stage all
python scripts/run_adapter.py --dataset hust --base-dir . --stage all
```

Supported dataset keys are:

```text
calce, hust, matr, nasa_pcoe, nrw, ora, rwth, xjtu
```

The adapter stages are:

- `extract`: convert original raw records into phase-specific extracted cycles;
- `clean`: standardize vectors, units, metadata, targets, and quality flags;
- `audit`: generate quality-control tables and optional plots;
- `all`: run extraction, cleaning, and audit in sequence.

## 2. Clean-cycle merge/copy

The feature extractor expects clean cycle files in:

```text
data/interim/charge/*.parquet
data/interim/discharge/*.parquet
```

Use your merge/copy script or manually place files generated by adapters into these folders with names such as:

```text
data/interim/charge/matr_charge_clean_cycles.parquet
data/interim/discharge/matr_discharge_clean_cycles.parquet
```

## 3. Hierarchical feature extraction v3

```bash
python scripts/run_feature_extraction_v3.py --base-dir . --workers 2 --resume --fast-mode --no-stages
```

Equivalent direct command:

```bash
python src/feature_extraction/build_hierarchical_features_v3.py   --input-root data/interim   --output-root data/processed/features_hierarchical_v3   --reports-root reports/feature_extraction_v3   --workers 2   --resume   --fast-mode   --no-stages
```

## 4. Feature extraction monitoring and inspection

```bash
python src/feature_extraction/check_feature_extraction_state_v3.py   --input-root data/interim   --output-root data/processed/features_hierarchical_v3   --reports-root reports/feature_extraction_v3   --state-root reports/feature_extraction_v3_state

python src/feature_extraction/inspect_features_v3_outputs.py   --features-root data/processed/features_hierarchical_v3   --interim-root data/interim   --reports-root reports/features_v3_inspection
```

## 5. Modeling dataframe

```bash
python scripts/run_modeling_dataframe.py --base-dir .
```

Equivalent direct command:

```bash
python src/modeling/build_modeling_dataframe_v1.py   --interim-root data/interim   --features-root data/processed/features_hierarchical_v3   --output-root data/processed/modeling_dataset_v1   --reports-root reports/modeling_dataset_v1
```
